# 호반써밋 브룩사이드 — 디자인 시스템 (e-카달로그)

| 토큰 | 값 | 출처 |
|---|---|---|
| --hb-terra | #CA6F5C | 강조어·컬러 블록·분양안내 헤더 (p.11~13, 22) |
| --hb-bg | #F1EFF2 | 동호수·평면 페이지 바탕 (p.17~21) |
| --hb-ink-2 | #595353 | 본문·안내 헤더 바 |
| --hb-74a / 74b / 84 | #9BC07D / #8190A5 / #CA6F5C | 주택형 컬러 코드 (p.16~21) |
| --hb-black | #0D0C0C | 견본주택 촬영 페이지 (p.3~5) |

- 서체: 헤드라인 Noto Serif KR Light(강조어만 테라코타), 로고 Montserrat Bold "SUMMIT" + 세리프 "HOBAN" + 와이드 "BROOKSIDE", 라벨 Barlow SemiBold, 본문 Pretendard.
- 모티프: 헤드라인 아래 짧은 테라코타 세로 라인 / 자간 넓은 영문 라벨 / 사진 위로 겹치는 테라코타 블록 패널 / 페이지 상단 "HOBAN SUMMIT BROOKSIDE" 러닝 헤더 / 로고+진회색 바 표 헤더.
- 신청 화면: 텍스트+라운지 사진 분할 히어로, 테라코타 상단 보더 폼, 주택형 컬러 카드 선택, 밑줄형 입력.
