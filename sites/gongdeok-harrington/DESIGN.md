# 공덕역 효성해링턴 스퀘어 — 디자인 시스템 (카탈로그 2016.01)

| 토큰 | 값 | 출처 |
|---|---|---|
| --hs-purple | #422C91 | 표지·인바이트 배경 (p.1~2) |
| --hs-charcoal | #231F20 | 시설 페이지 배경 (p.5~8) |
| --hs-taupe / -light | #A88272 / #C9A99A | 영문 Light 타이틀·한글 강조 (p.3~4) |
| --hs-gray | #E9E9E9 + 화이트 도트 | 사업개요 패널 (p.2) |

- 서체: 영문 Barlow(Light 300 + Bold 700 혼합, DIN 계열 대체), 대형 영문 Cinzel 와이드 자간 대문자, 국문 Pretendard. 로고는 카탈로그 표지 크롭 이미지.
- 모티프: 퍼플 위 가는 사각 프레임 라인 / 사진 모자이크 + 퍼플 세로 바 / 측면 세로 인덱스(▶ 현재 위치) / 섹션 eyebrow 앞 세로 가는 선 / 단면도 하단 퍼플 굵은 바.
- 신청 화면: 퍼플 헤더 패널(프레임 라인 + 배경 세리프 워터마크) + 흰 카드 폼 + 차콜 사이드 카드, 선택 칩은 퍼플.
